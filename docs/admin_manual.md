# 五行爭鋒 管理者手冊

> 更新日期：2026-07-28（對應目前 `main` 分支的完整功能）

---

## 1. 如何取得管理者權限

管理者身分是 `users.is_admin = 1`，目前**沒有後台介面可以自己升級成管理者**，需要直接操作資料庫：

```sql
UPDATE users SET is_admin = 1 WHERE username = '你的帳號';
```

登入後，導覽列會出現「管理後台」入口（`/admin`），且**角色頁面會額外顯示除錯工具面板**（見第 6 節）。

---

## 2. 管理後台總覽（`/admin`）

首頁固定顯示兩個站台統計數字（`@app.after_request` 自動追蹤，非管理員也會被計入）：

- **📊 網站瀏覽次數**：每一次非靜態資源的請求都會累計。
- **👤 不重複訪客數**：依瀏覽器 cookie（`visitor_id`）去重計算。

以下依序是各分頁功能。

---

## 3. 國家管理（`/admin` 首頁）

每個國家一張卡片，可編輯：

| 欄位 | 說明 |
|---|---|
| 國家名稱／主屬性／介紹文字 | 純顯示用文字 |
| HP／MP／力量／防禦／敏捷／幸運加成 (%) | 影響該國所有角色的六圍計算（`compute_final_stats`） |
| 國王／宰相／大將軍 | 下拉選單指定該國**現有角色**擔任，可選「（出缺）」清空 |

卡片上方也會顯示該國目前國庫金額（唯讀，僅供參考，目前沒有花費國庫的操作）。

---

## 4. 遊戲設定（`/admin/settings`）

### 回合與升級設定

| 欄位 | 說明 |
|---|---|
| 每回合等待秒數 | 移動/打怪/攻城等行動後的冷卻時間 |
| 基礎經驗值（1→2級所需） | 經驗曲線的起點 |
| 初心者／二轉／三轉／四轉成長率／級 (%) | 分階段的升級所需經驗複利成長率，各階段交界處會無縫接續（不斷層）；建議由高到低遞減，但系統不會強制檢查 |
| 轉生加成 (%/次) | 每次轉生疊加的永久六圍加成 |
| 裝備回收比例 (%) | 出售裝備可拿回原價的百分比 |
| 守衛怪遭遇機率 (%) | 每次打怪遇到守衛怪的機率 |
| 守衛怪經驗倍率／魔王經驗倍率 | 擊敗守衛怪/魔王時，經驗值 = 一般怪經驗 × 此倍率 |
| 商店稅率 (%) | 買賣裝備時流入國庫的稅率 |
| 回復站每點費用 | 回復 1 點 HP 或 MP 所需諸神幣 |
| 城鎮防衛等級／要塞防衛等級 | 攻城時 NPC 防衛隊的數值強度基準（`defense_tower_stats`），要塞必須 ≥ 城鎮，否則儲存會被拒絕 |

### 打怪場管理

- 4 個打怪場（初階/中階/高階/究極）可各自調整**建議等級區間**（最低/最高等級）。
- **注意**：怪物本身的數值、掉寶、經驗值目前無法在後台編輯——這些是 `db.py` 啟動時依區間公式生成的（每 5 級一個分區間，低→高兩端插值），要調整必須改程式碼後重新部署，不是後台可以做的事。

## 5. 使用者狀態（`/admin/sessions`）

顯示所有註冊帳號目前的線上/離線狀態、上次登入、最後活動、本次連線時長、閒置時間。閒置門檻由系統固定（頁面上方會標示目前的門檻分鐘數），超過門檻的使用者會在下一次請求時被自動登出，記錄為「閒置自動登出」。

---

## 6. 系統紀錄（`/admin/logs`）

- 顯示最近 200 筆註冊/登入/登出（含登入失敗）紀錄，含時間、帳號、動作、IP。
- 「清空紀錄」按鈕會**永久清空** `activity_log` 全部資料，此動作無法復原，按下前會有瀏覽器確認視窗。

---

## 7. 角色除錯工具（角色頁面 `/character` 下方，僅管理員可見）

這些工具是給管理員**自己的測試角色**用的，方便不用真的練等就能驗證轉職/轉生/四轉流程：

| 工具 | 說明 |
|---|---|
| 快速設定等級 | 直接把自己角色的等級改成指定數字，**會正確觸發精通判定**（跨過三轉 Lv120 邊界一樣會記錄精通），但等級提升的六圍加成用舊版固定公式概算，跟正常練等的隨機加點不會完全一致 |
| 快速設定轉生次數 | 直接改 `rebirth_count`，方便測試「轉生滿 3 次」的四轉資格條件，不會動到等級/職業/精通紀錄 |
| 🔄 重置為 1 級初心者 | 一鍵把自己角色打回等級 1、職業回到初心者、轉生次數歸零、清空所有精通紀錄與屬性下限，方便從頭重新測試整個轉職鏈；按下前有瀏覽器確認視窗，此動作無法復原 |

此外，管理員在「打怪」畫面（`/game`）會看到一個額外的**下拉選單，可直接指定要挑戰全遊戲 88 隻怪物中的任何一隻**（含所有守衛怪/魔王），繞過等級區間限制與守衛怪機率，方便單獨測試特定怪物或直接打魔王（不需先過守衛怪）。

---

## 8. 已知限制 / 尚未開放的後台功能

1. **沒有升級管理者的後台介面**——必須手動改資料庫 `users.is_admin`。
2. **怪物/商店物品沒有編輯介面**——只能調打怪場的等級區間，其餘寫死在程式碼。
3. **國庫沒有花費功能**——後台看得到各國國庫金額，但沒有任何扣款/使用的操作。
4. **國王/宰相/大將軍指派後沒有實際權限可管**——後台只能指定人選，遊戲內沒有對應的治理功能可用。
5. **系統紀錄只保留最近 200 筆、且沒有篩選/搜尋功能**，只能整批清空或整批看。
