# 諸神的黃昏 (Ragnarok Online)

以前玩過的網頁遊戲重製專案。

## 世界觀
玩家建立帳號後選擇五個國家之一，各國對應五行屬性，彼此間有相生相剋關係：

| 國家 | 屬性 |
|---|---|
| 百鍊流金國 | 金 |
| 翡翠靈木國 | 木 |
| 蔚藍千泉國 | 水 |
| 紅蓮業火國 | 火 |
| 萬物母育國 | 土 |

角色屬性：HP、MP、力量、防禦、敏捷、幸運。幸運值影響閃避與命中，金國角色初始幸運值較高。

## 開發狀態
目前僅有基礎專案架構與國家介紹頁面，帳號註冊/登入、角色創建等功能尚未實作。

## 執行方式
```bash
pip install -r requirements.txt
python app.py
```
